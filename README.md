# Product Information Experience System (PIEC)

project ini melakukan scan id pada rfid RDM6300 dan mengirimkannya ke pc lewat serial communicaton serta menampilkan response pada layar SSD1306 OLED display.

Hardware Requirement :
- ESP32
- RDM6300
- SSD1306 OLED 128x64

Software Requirement :
- RDM6300 library: https://github.com/arduino12/rdm6300
- SSD1306 OLED display library from adafruit.
